# Music Trainer

A premium web application scaffold for music education, built with React, Vite, React Router, and RTL Hebrew support.

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`
- `npm run lint`

## Deployment

This app is configured for GitHub Pages deployment at:
`https://michalamita-creator.github.io/music-trainer`
